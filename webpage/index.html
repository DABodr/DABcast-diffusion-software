Everything you need to run a DAB+ multiplex

📡

Full ODR-mmbTools integration

Manages odr-audioenc, odr-padenc, odr-dabmux and odr-dabmod in a coordinated process chain. Supports EASYDAB, EDI, HackRF and USRP output modes.

🔄

Audio-based failover watchdog

Detects stream failures via audio probing (not just HTTP checks). Automatically switches to a backup stream and returns to main when audio is restored.

🔔

Telegram bot notifications

Forwards logs and critical broadcast alerts to your Telegram bot. Choose the minimum log level, enable silent messages and verify the connection with a built-in test.

🎵

Live metadata — DLS & SLS

Pushes Now Playing text and album art to listeners in real time. Supports direct stream metadata, JSON API polling and DL+ tags.

⚡

Lightweight & Raspberry Pi ready

Runs on amd64 servers and Raspberry Pi 4/5 (arm64). Ships as a self-contained .deb package — no Node.js installation required on the target system.

🖥️

Browser-based interface

Clean dark-themed UI accessible from any device on your local network. No desktop environment required on the broadcast server.

🔐

Integrated secure sign-in

Branded responsive login with signed sessions, persistent sign-in, brute-force protection and automatic session invalidation after a password change.

📦

Preset management

Save and restore complete multiplex configurations as JSON presets. Import/export individual services or full configurations with a single click.

🔁

One-click over-the-air updates

DABcast checks for new releases automatically. When an update is available, install it with a single click — the service restarts and the page reloads on its own.
