Everything you need to run a DAB+ multiplex

📡

Full ODR-mmbTools integration

Manages odr-audioenc, odr-padenc, odr-dabmux and odr-dabmod in a coordinated process chain. Feeds several transmitters at once: EasyDAB V2 (ZMQ), commercial modulators (EDI/UDP, multicast), converters and remote sites (EDI/TCP), raw ETI — with their connection state.

🔄

Audio-based failover watchdog

Detects stream failures via audio probing (not just HTTP checks). Automatically switches to a backup stream and returns to main when audio is restored.

🔔

Telegram bot notifications

Forwards logs and critical broadcast alerts to your Telegram bot — encoder crash, failover, an SDR that stops transmitting, a transmitter that disconnects — and, if you wish, a ✅ RESOLVED message when it is back on air. Minimum level, silent messages and a built-in test.

🎵

Live metadata — DLS, DL+ & SLS

Now Playing text, DL+ tags and album art in real time, from the stream (ICY), a JSON API (Server-Sent Events feeds included) or manual text. Covers alternate with your logo, and the logo comes back on its own during ads. Slides are converted to 320x240 with side bands in the picture's own colours.

⚡

Lightweight, Raspberry Pi ready, one-click updates

Runs on amd64 servers and Raspberry Pi 4/5 (arm64) as a self-contained .deb package — no Node.js to install. New releases are found automatically and installed with a single click: the service restarts and the page reloads on its own.

🖥️

Control-room web interface

Dark UI with live summary cards (capacity, CPU, memory, disk), service search, sort and compact view, usable from any device on your network. Secure sign-in, and a ⚙ Settings window for the account, password and web port.

📊

Mux input monitoring

Reads the odr-dabmux input buffers of every service: underruns, silence or missing audio are flagged live — even when the encoder process still looks healthy.

📦

Preset management

Save and restore complete multiplex configurations as JSON presets. Import/export individual services or full configurations with a single click.

📻

SDR output — HackRF, LimeSDR… New

Transmit from the server itself: odr-dabmod drives the SDR through SoapySDR, alongside the network outputs. If the device is unplugged, DABcast notices it, keeps the rest of the multiplex on air and restarts the SDR as soon as it is back.

🎧

Web player New

Listen to any service of the multiplex in the browser, decoded from the mux output itself: what you hear is what receivers get. Level meters, DLS, DL+ and slides with their size in kB.

🎚️

Audio levels assistant New

Measures each service over 5 to 30 minutes, flags encoder clipping and suggests a gain that keeps 3 dB of headroom for AAC. Apply it in one click: only that service's encoder restarts.

🧭

Guided service setup New

Test a stream URL and see its current title, detect the artist / title / cover keys of a JSON API automatically, and get live hints on PI, PS8 / PS16 and multiplex capacity while you type.

Quick install — the tools and DABcast in one command
# Installs the ODR-mmbTools, the SDR drivers AND DABcast itself (latest release, amd64 or arm64),
# then starts DABcast as a service. Debian 12 / 13, Raspberry Pi OS 64-bit, Ubuntu 26.04+
wget https://dabodr.github.io/DABcast-diffusion-software/download/install-tools.sh
sudo bash install-tools.sh
# Open http://<server-ip>:9090 — first login admin / dabcast, a new password is asked at once
Or by hand — the tools, then the DABcast package yourself
# 1. The tools only, without DABcast (ODR-mmbTools, SDR drivers…)
sudo bash install-tools.sh --tools-only

# 2. The DABcast package — on a Raspberry Pi take the arm64 one (button above)
wget https://github.com/DABodr/DABcast-diffusion-software/releases/download/v1.10.3/dabcast_1.10.3_amd64.deb
sudo dpkg -i dabcast_1.10.3_amd64.deb
